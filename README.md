# Mohamed Daoud — Portfolio

Open the portfolio: [mdaoudoda.github.io/Mohamed-Daoud-portfolio](https://mdaoudoda.github.io/Mohamed-Daoud-portfolio/)

`index.html` at the root only opens the deck. The slides live in `slides/`. The curriculum vitae is `assets/cv.html` and is not part of the slide navigation.

Every slide uses the navy and ice palette in `assets/css/shell.css`. Shared frame, scaling, and print behavior live in `assets/css/shell.css`, `assets/js/canvas-fit.js`, and `assets/js/deck.js`.

| # | Slide | HTML | CSS |
| --- | --- | --- | --- |
| 01 | About Me | `slides/index.html` | `slides/about.css` |
| 02 | Career and Education | `slides/career.html` | `slides/career.css` |
| 03 | Technical Stack | `slides/skills.html` | `slides/skills.css` |
| 04 | Projects | `slides/projects.html` | `slides/projects.css` |
| 05 | Center of Interest | `slides/personal.html` | `slides/personal.css` |

The header tabs and the footer arrows follow that order. The print icon prints all five slides, one page each.

Edit the wording in the slide HTML. Edit that slide's layout in its CSS file.
